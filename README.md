# Student Performance Analytics System

**Course:** Python with AI  
**Student name:** Sarthak Rana 
**Project type:** Python data analysis mini project

## Objective
Analyze student marks and attendance with Python, NumPy, and Pandas. The program calculates totals, averages, grades, pass/fail results, subject statistics, and top performers.

## Technologies
- Python
- Pandas
- NumPy
- CSV dataset

## Files
- `main.py` — main program
- `students.csv` — sample dataset containing 20 students
- `requirements.txt` — required Python packages
- `Project_Documentation.docx` — project report template
- `student_results.csv` — generated after running the program

## Grading and pass rules
- A+: average >= 90
- A: average >= 80 and < 90
- B: average >= 70 and < 80
- C: average >= 60 and < 70
- D: average >= 50 and < 60
- F: average < 50
- Pass: at least 40 marks in **every** subject; otherwise Fail.

These are project-defined rules and can be changed if your trainer specifies different rules.

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
4. Run:
   ```bash
   python main.py
   ```
   If `python` is not recognized on Windows, try `py main.py`.
5. Review the terminal output and the generated `student_results.csv`.

## Analysis included
- Student-wise total marks, average, grade and result
- Class average, highest/lowest student average and pass percentage
- Average attendance
- Top three students
- Average, highest and lowest marks per subject
